# 庭审提纲起草技能

## 核心定义

庭审提纲是代理人在开庭前准备的作战地图，覆盖程序核对、法庭调查、质证、法庭辩论各环节的发问与应对要点。

## 输出结构

### 一、庭前核对
- 当事人及代理人信息、代理权限（特别授权逐项列明）
- 案号、承办法官、开庭时间地点、是否简易/普通程序
- 举证期限是否届满、是否有逾期证据需说明

### 二、法庭调查（按我方立场）
- **陈述提纲**：事实按时间线提炼为 5-8 个要点，每个要点标注对应证据编号（与证据清单联动）
- **发问提纲**：向对方当事人/证人的问题清单，每题预设对方可能的回答与追问路径
- **答辩要点**：预判对方主张 → 逐项写明抗辩理由 + 对应法条（注明条号）+ 对应证据

### 三、质证提纲（对对方每组证据）
| 对方证据 | 真实性 | 合法性 | 关联性 | 质证意见 | 降权策略 |
| -------- | ------ | ------ | ------ | -------- | -------- |

### 四、法庭辩论
- 争议焦点归纳（预判 2-4 个焦点）
- 每个焦点：我方观点 → 法律依据（《XX法》第X条）→ 事实依据（证据编号）→ 类案/公报案例参考

### 五、风险与预案
- 我方证据链薄弱环节及庭上补救话术
- 调解底线与让步空间（与当事人庭前确认）

## 起草规则

1. 所有法条引用必须先用 law_get / law_search 核实原文，再写入提纲。
2. 发问题目避免诱导性提问（法庭会制止）；预设追问不超过两层。
3. 质证遵循"三性+证明力"框架，先定性质再展开理由。
4. 内容确认后调用 document_render 生成 Word（format: "litigation"），文件名如「XX案庭审提纲-YYYYMMDD.docx」。
