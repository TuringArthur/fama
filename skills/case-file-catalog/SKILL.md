# 卷宗目录编制技能

## 核心定义

卷宗目录是诉讼档案整理时置于卷首的材料清单，逐项列明卷内文书的顺序号、文号/日期、标题、页码，是法院档案管理与律师归档的规范要求。

## 输出结构

| 序号 | 文书名称 | 日期 | 页码 | 备注 |
| ---- | -------- | ---- | ---- | ---- |
| 1 | 起诉状 | 2024-03-01 | 1-3 | 正本 |
| 2 | 受理案件通知书 | 2024-03-05 | 4 | |
| 3 | 授权委托书 | 2024-02-28 | 5 | 附所函 |

## 编排规则

1. **正卷顺序**（民事一审常规）：起诉状及附件 → 受理通知 → 答辩状 → 证据材料 → 开庭传票及回证 → 庭审笔录 → 调解书/判决书 → 送达回证。
2. **副卷**：合议庭评议笔录、审委会讨论记录等不对外材料（律师归档时按律所内部规范处理）。
3. **页码连续**：卷内所有材料统一编连页码；目录页码列与实际编页严格一致。
4. **日期取文书落款日**；无落款日的取收到日并在备注注明。
5. **案号与卷别**：目录抬头注明案号、当事人、卷别（正卷/副卷）、整理人与整理日期。

## 交付

- 与用户逐项核对材料清单后，调用 document_render 生成 Word（format: "plain"，文件名如「(2024)京0108民初1234号卷宗目录.docx」）
