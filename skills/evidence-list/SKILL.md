# 证据清单整理技能

## 核心定义

证据清单是诉讼或仲裁中随证据材料提交、供法庭（仲裁庭）和对方当事人查阅的证据目录文件，需逐项载明证据编号、名称、来源、证明对象、页码与原件/复印件情况。

## 输出结构

使用如下表格结构（Markdown 表格先与用户确认内容，再以 document_render 渲染 Word，format 取 "plain"）：

| 编号 | 证据名称 | 证据来源 | 证明对象 | 证据形式 | 页码 | 备注 |
| ---- | -------- | -------- | -------- | -------- | ---- | ---- |
| 1 | 《买卖合同》 | 原告持有 | 双方买卖合同关系及约定内容 | 原件 | 1-5 | 签订于2024年3月 |
| 2 | 微信聊天记录 | 原告手机 | 催款事实及被告承认欠款 | 打印件（当庭出示原始载体） | 6-12 | 已公证的可注明公证书编号 |

## 整理规则

1. **分组排序**：按「书证 → 物证 → 视听资料 → 电子数据 → 证人证言 → 鉴定意见 → 勘验笔录」的法定证据种类分组，组内按证明逻辑或时间排序。
2. **证明对象要具体**：写明"证明什么事实、对应哪个要件"，避免"证明案件事实"这类空泛表述。
3. **三性预判**：可在备注列标注该证据可能受到的质证挑战（真实性/合法性/关联性）及应对思路。
4. **载体提示**：电子数据注明"当庭出示原始载体"；复印件注明原件存放处。
5. **缺证提示**：对举证期限内可能无法取得的关键证据，提示用户考虑申请法院调查取证或证据保全。

## 交付

- 用户确认清单内容后，调用 document_render 生成 Word（format: "plain"，文件名如「XX案证据清单.docx」）
- 提交前运行 citation_check 核验文中法条引用
